# Code of conduct

Be kind and be useful. Everyone taking part in issues, pull requests and discussions is expected to:

- treat others with respect and assume good faith;
- keep feedback about the work, not the person;
- not harass, demean, or discriminate against anyone.

Maintainers may edit, hide or remove contributions that break these rules, and may block repeat offenders.
Report problems privately to the maintainer through the contact on their GitHub profile.
